# ✨ Ты изменила мою вселенную

Сайт-признание / сайт-извинение: о том, как девушка осчастливила тебя и изменила твою жизнь.
Полностью на клиенте (HTML + CSS + JS), без сборки и зависимостей.

## Как запустить

```bash
cd apology-site
python3 -m http.server 8080
```

Или просто открой `index.html` в браузере.

## Что внутри

- 🎬 Кинематографичное интро «до тебя была просто ночь…»
- 🌌 Живой космос: мерцающие звёзды, туманности, падающие звёзды, всплывающие сердца
- 💥 Сердца-салюты при каждом клике + след за курсором + кастомный курсор
- 🎵 Генеративная эмбиент-музыка (синтезируется в браузере, без файлов)
- 🌗 Раздел «До тебя / С тобой»
- 🔢 Анимированные счётчики: дни вместе (считаются сами), улыбки, бессонные ночи…
- 🕰️ Таймлайн вашей истории
- 💗 Созвездие-сердце (реагирует на курсор, пульсирует)
- 💌 Письмо-извинение
- 😅 Финал «Простишь меня?» — кнопка «Нет» убегает, «Да» вызывает салют
- 🥚 Пасхалка: набери на клавиатуре «люблю» или «прости»

## ⚙️ Как настроить под себя

Всё главное — в начале файла **`app.js`**, в объекте `CONFIG`:

| Поле | Что поменять |
|---|---|
| `yourName` / `herName` | ваши имена (используются в письме) |
| `startDate` | дата начала отношений в формате `ГГГГ-ММ-ДД` — дни посчитаются сами |
| `milestones` | главы вашей истории (дата, заголовок, текст) |
| `reasons` | причины, почему ты её любишь (эмодзи + текст) |
| `constellationText` | подпись под созвездием |
| `counters` | числа-счётчики (кроме дней — они считаются от `startDate`) |

Текст письма-извинения — в `index.html`, в секции `#letter` (блок `[напиши здесь своими словами…]`).
Слова интро, заголовки и список «До / После» тоже редактируются прямо в `index.html`.

## Как отправить ей

1. Разверни сайт на бесплатном хостинге статики:
   **GitHub Pages**, **Netlify Drop** (просто перетащи папку `apology-site` на netlify.com/drop) или **Vercel**.
2. Получи ссылку вида `https://что-то.netlify.app`.
3. Отправь ей ссылку с сообщением — интро само её заинтригует. 💌
