Ссылка в коде: **https://ketchuneziko.github.io/iloveyouMariya/**

## картинки

| файл | зачем |
| --- | --- |
| `qr-embed.png` | 1080×1080, без текста — стоит на сайте в блоке «наведи камеру» |
| `qr-night.png` | 1200×1500 ночная карточка: отправить, распечатать, поставить на обои |
| `qr-blush.png` | 1200×1500 светлая карточка: красиво печатается на бумаге |
| `qr.svg` | вектор — можно печатать хоть на стену, сердце в центре на месте |
| `qr-plain.png` | строгий чёрно-белый — на случай очень капризной камеры |

Все версии **реально читаются**: модули-сердечки, «глазки» и сердце в центре подобраны так,
чтобы код распознавался даже в маленьком превью (проверено: читается вплоть до ~15% от исходного размера,
при повороте, размытии, сумраке и после JPEG-сжатия). Точность коррекции ошибок — Q (25%),
поэтому пятно от сердечка в центре камере не мешает.

## если захочешь переделать (другая ссылка, другие слова)

```bash
pip install qrcode pillow            # + opencv-python-headless, чтобы сам проверил читаемость
python3 tools/make-qr.py --url https://твой-домен./site/
```

Полезные флаги:

- `--url` — какая ссылка зашита (по умолчанию — GitHub Pages этого репозитория)
- `--module heart|round|square|dot` — форма модулей (сердечки / кружочки / квадратики)
- `--fill 0.94` — насколько крупно сердечко в своей ячейке
- `--logo 0.185` — размер сердечка в центре (`0` — убрать совсем)
- `--finder-round 0.6` — скругление «глаз»; больше 0.8 камеры уже начинают путаться
- `--ecc LMQH` — запас прочности; `H` — самый упрямый, но кода станет плотнее

Шрифты для надписей (Cormorant Garamond / Manrope) скрипт ищет в `assets/fonts/`,
потом в системе; без них возьмётся любой DejaVu — картинка всё равно соберётся.
Тексты карточки (заголовок, «для Марии», 143 ♥ 520) — в `tools/make-qr.py`, блок `card_configs()`.
